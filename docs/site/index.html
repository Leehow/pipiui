特性

项目与会话

多会话并行，后台会话继续跑，费用与上下文实时可见。

流式聊天

Markdown、工具卡片实时输出、Thinking 折叠块，斜杠命令补全。

内置浏览器

面板 + pi browser 工具：navigate / content / eval / console / screenshot。

Subagent 与 Boss

实时树状面板；Boss 大组长模式自动派工扇出。

Computer Use

可选的 macOS 桌面控制，需要时再打开。

远程接管

手机或浏览器经透明 relay 接管会话（remote.deepwood.cn）。

附件与链接

多图附件、路径链接，会话里直接打开本地文件。

Memory

学习循环扩展，把项目习惯沉淀下来。

主力发行版为 Electron（macOS / Windows / Linux）。Swift 原生版已冻结，不再主推。
