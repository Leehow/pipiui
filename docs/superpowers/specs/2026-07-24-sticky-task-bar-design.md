# 任务消息吸顶（Sticky Task Bar）— 设计文档

- **日期**：2026-07-24
- **状态**：已批准（brainstorming），待 spec 审阅 → writing-plans

## 1. 背景与问题

长回复（Thinking / 工具卡 / subagent）会把用户发出的任务气泡顶出视口。用户往下滚时看不到「当前在做什么」，只能再滚回去找。

会话顶栏已有 `navigationTitle`（短标题，如「额度显示不更新问题」），但那是摘要，不是任务原文。用户需要的是：**任务原文在滚出视口后仍能以压缩形式固定在聊天区顶部**。

中间穿插的短确认（「好的」「继续」「a」「b」）不应抢走吸顶目标。

## 2. 业界对照（已调研）

| 产品 | 行为要点 | 对我们的启发 |
|------|----------|--------------|
| Cursor（社区标杆） | 当前用户提问吸顶 | UI 目标形态 |
| Claude Code（源码 `StickyPromptHeader`） | 视口外 user 文案压成固定高度 1 行；点击跳回；只取第一段；高度锁死防 jump | 压缩副本 + 点击跳回 + 固定高度 |
| Hermes | 视口内仍有 user 则不钉；滚出后显示 `↳` + 截断文案 | 视口触发，避免双份 |
| Zed（PR #59316） | 段落吸顶、长文折叠、下一条顶掉上一条 | 复杂度高；本版不做段落切换 |
| Claude Code VS Code（issue #49114） | CSS `position: sticky` 钉整条用户消息 → 长消息盖住助手回复 | **禁止**整气泡 sticky |

公开实现里**没有**「≥20 字才算任务」的阈值；一般钉所有真实 user 消息。短确认过滤是 PipiUI 额外规则。

## 3. 目标 / 非目标

**目标**
- 钉**最近一条可钉**的用户任务消息（新任务替换目标；短确认不替换）。
- 目标滚出视口上方后，聊天区顶部显示压缩顶栏；原文回到视口则隐藏。
- 点击顶栏滚回原文。
- 可钉判定用规则 C（见 §4.1）；纯逻辑可单测。

**非目标**
- 不做 Zed 式「按滚动段落切换吸顶目标」。
- 不做顶栏内展开全文（点回去看原文即可）。
- 不改 pi / jsonl / 会话存储。
- 不替代或改写 `navigationTitle` 会话标题逻辑。

## 4. 设计

### 4.1 可钉判定（规则 C）

对一条 `role == "user"` 的消息，取展示用纯文本（与 `MessageRow` 同源，剥离附件脚注路径等），并检测是否有图片附件。

**永不钉**
- 文本以 `[subagent-done]` 开头，或含 `PipiUI internal`
- 空文本且无附件

**不钉（短确认）**
1. 去首尾空白后，整句匹配黑名单（大小写不敏感，拉丁文 lower）：  
   `好的` `好` `继续` `ok` `okay` `yes` `y` `a` `b` `嗯` `行`（实现时集中常量表，可扩展）
2. 去空白后长度 ≤ 2 **且** 无图片附件

**可钉**
- 有图片附件 → 可钉
- 正文含换行 → 可钉
- 其余未命中上述排除的用户文本 → 可钉  
- **不设**「长度 ≥ 20」门槛（避免误杀「修滚动」「用方案 A」）

**选目标**：从 `transcript` 从后往前找第一条可钉用户消息。找不到则无吸顶目标。

### 4.2 显示与交互

| 条件 | 行为 |
|------|------|
| 无目标，或目标仍在视口内（含部分可见） | 不显示顶栏 |
| 目标完全滚出视口**上方** | 显示顶栏 |
| 点击顶栏 | `scrollTo` 目标 `item.id`；顶栏随原文入视口而隐藏 |
| 贴底跟随流式输出 | 不改变现有 `pinTranscriptToBottom`；若目标已在上方外，顶栏仍可显示 |

**外观（学 Claude Code / Hermes）**
- 压缩副本条，不是完整蓝气泡。
- 固定最大高度约 2～3 行；超出截断省略。高度稳定，避免切换文案时布局 jump。
- 文案：`trimStart` → 只取第一段（空行前）→ 空白压成单空格 → 再按行/字符上限截断。
- 轻量前缀（如 `↳`）+ 贴近用户气泡色的半透明底 + 底部分隔线。
- 挂在 transcript `ScrollView` **外侧**（`safeAreaInset(edge: .top)` 或顶对齐 overlay），避免消息流内 CSS sticky 盖内容的坑。
- 与右下角「回底部」按钮并存。

### 4.3 技术落点

| 单元 | 职责 |
|------|------|
| `TaskPinLogic`（新建，纯函数） | 可钉判定、最近可钉选取、顶栏展示文案压缩 |
| `StickyTaskBar`（新建 View） | 顶栏 UI；接收文案 + `onTap` |
| `ChatDetailView` | PreferenceKey / 几何跟踪目标是否在视口上方外；驱动顶栏显隐与 `scrollTo` |

状态为会话级 UI 状态（跟 `session.id` 重置），不写磁盘。

**边界：`transcriptVisibleCount`**
- 目标不在当前 suffix 时：仍可用已解析文本显示顶栏。
- 点击：若目标不在可见 suffix，先增大 `transcriptVisibleCount`（或等价露出该条）再 `scrollTo`。

### 4.4 测试

**单元（`TaskPinLogic`）**
- 黑名单不钉；≤2 字无附件不钉；有附件可钉；多行可钉；短真实任务（如「修滚动」）可钉。
- `[subagent-done]` / internal 不钉。
- 从后往前选取：中间插入「继续」不改变目标；新可钉消息替换目标。
- 展示文案：第一段 + 空白折叠 + 截断。

**手工**
- 长助手回复下滚 → 顶栏出现；上滚见原文 → 顶栏消失；点击跳回。
- 发「好的」→ 顶栏仍是原任务；发新任务 → 顶栏换新。
- 贴底流式时顶栏不破坏回底部按钮。

## 5. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 几何跟踪误判导致闪烁 | 用「完全滚出上方」阈值；必要时小滞后，避免贴边抖动 |
| 长任务文案占满顶栏 | 硬顶 2～3 行 + 省略 |
| 可见窗口截断导致点不回去 | 点击前扩展 `transcriptVisibleCount` |
