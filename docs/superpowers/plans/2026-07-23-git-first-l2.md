# Git-first L2 — Structured status/diff + VCS roadmap

**Goal:** Extend L1 toolbar git with dirty/upstream fields, agent tools (`git_status` / `git_diff`), system-prompt snapshot, and a Chinese VCS roadmap (L0–L5).

**Architecture:** Keep pure Foundation `GitRepo` parsers + `probe` for UI; ship `GitExtension` (TS, Application Support, `-e`) for agent tools and `before_agent_start` snapshot. No libgit2. No shell-string git.

**Tech Stack:** Swift Process, SwiftUI Menu help/`*`, Node `spawnSync` argv, Pi `ExtensionAPI`.
