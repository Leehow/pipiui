发送失败时，点错误旁的「更多」查看详情，再点「复制诊断信息」，把复制的文字发给客服。桌面版内置 Flapcode 0.1.1。可在「设置 → 更新中心」下载软件更新并重启安装，也可独立更新插件。还没有更新中心的旧版本请先从本页下载安装一次。

同一个 App 的两种发行物。基础版是新项目的默认形态：通用工作台、会话、模型与扩展管理。Coding 优化版额外内置 Office、PDF 与代码检索三个扩展（约 125 MB），装了它才有这三项能力——两个包都能在应用内切换 Profile。

GitHub 仓库

特性

项目与会话

多会话并行，后台会话继续跑，费用与上下文实时可见。

流式聊天

Markdown、工具卡片实时输出、Thinking 折叠块，斜杠命令补全。

内置浏览器

面板 + pi browser 工具：navigate / content / eval / console / screenshot。

Subagent 与 Boss

实时树状面板；Boss 大组长模式自动派工扇出。

Computer Use

可选的 macOS 桌面控制，需要时再打开。

远程接管

手机或浏览器经透明 relay 接管会话（remote.deepwood.cn）。

附件与链接

多图附件、路径链接，会话里直接打开本地文件。

Memory

学习循环扩展，把项目习惯沉淀下来。

主力发行版为 Electron（macOS / Windows / Linux）。Swift 原生版已冻结，不再主推。
