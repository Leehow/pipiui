# 斜杠命令实机验收清单

**前提**：`swift build` 绿；`swift run` 启动 App；已装 pi CLI；打开或新建一个会话。

勾选方式：通过 `[x]`，失败在项后附现象。

## 浮层与过滤

- [ ] **浮层出现**：在输入框输入 `/`，浮层弹出，至少可见 8 条内置命令（`/compact` `/new` `/name` `/session` `/export` `/copy` `/quit` `/model`）
- [ ] **服务端候选**：会话加载完成后，若 pi 返回 `get_commands`，浮层出现 extension/prompt/skill（徽标 `ext` / `prompt` / `skill`）；失败时仅内置、无报错刷屏
- [ ] **徽标**：内置行显示 `builtin`；服务端行按来源显示对应徽标
- [ ] **实时 fuzzy 过滤**：输入 `/sn` 等子序列可匹配 `session`（及名称含该子序列的服务端命令）；输入继续收窄列表
- [ ] **空格关浮层**：输入 `/model `（命令名后空格）后浮层关闭，可继续手打参数

## 键盘与点击

- [ ] **↑↓ 选择**：上下键移动高亮，到顶/底不再越界（clamp）
- [ ] **Tab 补全**：Tab 将选中项补全为 `/name `，焦点仍在输入框，浮层关闭，可继续打参
- [ ] **点击 = 补全**：鼠标点击候选行效果同 Tab（只补全、不立刻执行）
- [ ] **Return 执行**：浮层打开时 Return 执行当前选中命令，draft 清空
- [ ] **Return 不双发**：执行后聊天区不会同时再出现一条把 `/xxx` 当普通用户消息发出的气泡（无双发）
- [ ] **Esc 关闭**：Esc 关闭浮层，draft 保留，不发送
- [ ] **浮层关闭时 Return**：无浮层时 Return 仍按原逻辑发送普通消息
- [ ] **⌘V 粘贴不受影响**：浮层开/关时 ⌘V 仍能粘贴文本到输入框（不与斜杠 monitor 冲突）

## 内置命令行为

- [ ] **`/compact`**：执行后出现压缩相关系统/状态提示（compaction）
- [ ] **`/name Hello`**：侧栏或标题会话名更新为 Hello
- [ ] **`/name` 无参**：错误/用法提示（flash/banner），不静默失败
- [ ] **`/session`**：banner 显示费用 / 上下文 / 模型等摘要
- [ ] **`/export`**：成功后有 HTML 路径提示，并在 Finder 中选中导出文件
- [ ] **`/copy`**：在已有 assistant 文本回复后执行，剪贴板为该文本；无 assistant 文本时 flash 提示
- [ ] **`/new`**：新建并选中新会话
- [ ] **`/quit`**：当前会话关闭/移除
- [ ] **`/model` 无参**：flash 提示使用底栏模型菜单
- [ ] **`/model <provider/id>`**：使用底栏菜单里真实存在的 id，模型切换成功
- [ ] **未知 `/unknown-foo-xyz`**：当作普通用户消息发出，聊天区出现对应气泡

## 忙时（流式生成中）

- [ ] **内置立即执行不入队**：模型正在生成时执行 `/compact`（或 `/session`），立即生效，不出现在 follow-up 队列条
- [ ] **服务端命令经队列**：生成中执行某条服务端 slash（或依赖 prompt 的命令），进入队列条；空闲后按序发送
- [ ] **普通文本仍可入队**：生成中输入普通文本发送，行为与改斜杠前一致（入队）

## 可选韧性

- [ ] **get_commands 失败**：异常/旧版 pi 下应用仍可用，浮层仅内置，无 get_commands 报错刷屏
