# code-retrieval

Bundled dual-half extension (`id="code-retrieval"`). Skeleton only: four
degraded tools, invoke `status`/`reindex`, and a toolPanel status view.

Build: `tsc -p agent/tsconfig.json && tsc -p app/tsconfig.json`

Sidecar binaries and tree-sitter WASM are not shipped in this skeleton (D7).
